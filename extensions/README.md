# 扩展与存档

这里放的不是核心链路，是暂时用不上、但以后可能捡回来的东西。
主程序运行不依赖这个目录，删掉也不影响启动。

| 文件 | 是什么 | 为什么放这里 |
|---|---|---|
| `old-readme.md` | 早期的 README | 里面的说法和现在的代码对不上（例如「SparkSQL 仍在规划中」），留作历史 |
| `evaluator_rag.py` | 检索加回答的评测脚本 | 与 `evaluation/agent_test_cases.json` 里的 rag 用例重复，且判定只看关键词 |
| `legacy_results/` | 早期跑出来的三份结果 | 用例集和现在的不一样，不能和新结果直接比较 |

要用的时候从这里拿，不要直接引用，避免主目录越来越乱。
