# 项目简介

这是一个用自然语言查电商数据的分析助手。用户不需要写 SQL，把想看的问题用中文说清楚，系统负责翻译成查询语句、执行、再把结果讲成人话。

解决的问题是取数慢：业务人员要一个指标，得提需求、等排期、等开发写 SQL，一来一回两三天。这套系统把这个过程压成一次对话。

系统由三部分组成。数据侧用 MySQL 做 ODS、DWD、DWS 三层加工，五张汇总表覆盖商品、品牌、品类、每日趋势、用户价值五个视角。服务侧用 FastAPI，负责意图路由、生成查询、校验、执行和回答。前端用 Vue，一个对话页、一个看板页。

模型只面对汇总层，看不到明细表。汇总表的字段少、含义清楚，模型选错表和字段的概率低，生成的 SQL 也短，调用便宜。
